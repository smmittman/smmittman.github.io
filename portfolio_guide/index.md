# Portfolio Guide
## Welcome to my guide!

## Introduction
I created my e-portfolio to showcase my academic projects, professional background, and core skills in business and management. This guide outlines the step-by-step process I followed to build, structure, and customize my personal website using GitHub Pages.

## Step-by-Step Guide to Setting up my E-Portfolio:
* I began with creating my GitHub account, smmittman.
* Next, I created the Repository in which my e-portfolio would be built, smmittman.github.io    [Check it out!](https://github.com/smmittman/smmittman.github.io)
* I cloned my Repository to create a local copy of my project on my computer so that I could work on my code directly within my own development environment. To clone a Repository, click the drop-down arrow next to the green **Code** button and select 'Clone'.

## Adding a Theme:
* For this project, I used the [Minimal Theme](https://github.com/pages-themes/minimal)
* Un
* I downloaded the entire minimal project by clicking **Code** then **Download ZIP**
* Then I had to unzip the folder and extract the files to add them to my cloned Repository and committed the changes, which saved my progress.

## Replacing the logo.png Stock Photo With My Headshot:
* Among the files from the Minimal Theme is a folder titled 'assets'. Within this folder is a subfolder named 'img'. This folder contains the stock photo ('logo.png') which comes with the Minimal Theme.
* To change this photo out, I selected an appropriate photo of myself, retitled it 'logo.png' and swapped out the stock photo.

## Structuring My E-Portfolio:
* Another file from the Minimal Theme is index.md. This is where most of the editing I performed happened so that I could set my e-portfolio up exactly how I wanted it.
* I built my e-portfolio following a similar format to that of a resume: summary, work experience, education
* I also embedded a link to my LinkedIn profile by using brackets [ ] around the words 'Visit My LinkedIn' and the parenthesis around the page address for my profile so that it shows up as a quick-link like this: [Visit my LinkedIn](https://www.linkedin.com/in/stefanie-mittman-4a006b3b5/?isSelfProfile=true)

## Finalizing My E-Portfolio:
* Once I had double-checked my code and previewed my profile to make sure everything looked the way I wanted it to, I selected **Commit Changes...** to save my work.
